How to use

  1. 1Set Radius - circle size in blocks (bigger number = bigger circle).
  2. 2Pick Filled or Outline - filled for floors, outline for walls and towers.
  3. 3Build in game - place blocks where you see orange squares. Numbers tell how many blocks go in a row.
Place a block here 5 = place 5 blocks in this row

Start from the center and build one quarter first, then mirror it to the other sides. The numbers appear only in the top-right quarter to keep the plan clean.
